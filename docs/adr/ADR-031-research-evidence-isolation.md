# ADR-031 — Aislamiento de evidencia pública y privada

- **Estado:** propuesto
- **Fecha:** 2026-08-14

## Decisión

Planes, requests y evidencia declaran owner/project scope y visibilidad. La
evidencia privada nunca se reutiliza fuera de autorización; la pública requiere
fuente, licencia, región, vigencia y política explícita.

## Consecuencias

No se comparten secretos ni datos de cuenta por optimización. La reutilización
global futura exigirá controles de autorización y procedencia.
